# Lil Horny — Project Info

Lil Horny is released under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode.en). Please follow that license.

All project files are in this folder, and the project is updated regularly on
[Google Drive](https://drive.google.com/drive/folders/10FEdRLiF6wVrJK5k8aDCwKiYdItE1z3n?usp=drive_link).

The frame is based on the **Fractal 65**, created by Fractal Engineering; all credit goes to them.
In my testing I used a cut-down Pavo Pico frame and a cut-down Fractal 65. All prints work with both.

## Build List

- **TBS Lucid AIO 1-2S** (the battery mount is made for this and fits around the plugs)
- **DJI O4 Lite** (the camera mount is made for this)
- **Gemfan 123D** propellers
- **0802 16000kv** motors

Fits 200 mAh to 300 mAh 2S packs with the same battery mount:

- <https://www.amazon.com/dp/B0D3F5YF9L>
- <https://www.amazon.com/dp/B0GXZCW923>

## ESC (AM32)

- AM32 updated to 2.21
- 12 pole motor count (important with smaller motors)
- Maxed out KV

## Betaflight

- Betaflight 4.5.1 (also set to 12 pole motor count)
- 3D settings: 1504 high, 1496 low, 1500 mid
- 3D deadband in the Receiver tab set to 3

Full CLI settings: [`Tune/Lil Horny 3D Master Tune.txt`](Tune/Lil%20Horny%203D%20Master%20Tune.txt)
