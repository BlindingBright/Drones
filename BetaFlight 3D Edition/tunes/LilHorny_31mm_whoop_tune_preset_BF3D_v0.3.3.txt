# ==============================================================================
# BetaFlight 3D Edition: 31 mm 3D WHOOP TUNE (paste-in), "Lil Horny" for BF3D v0.3.3-test (Betaflight 2026.6.2)
#
# This is NOT a full `diff all`: it changes the tune only and never touches your board, ports, switches, motor order or rates, so it
# is safe to paste on any 1S-2S 3D whoop. (A real `diff all` starts with `defaults` and your board name and would wipe your own setup.)
#
# ZoeFPV's "Lil Horny": TBS Lucid AIO 1-2S, 31 mm props, AM32 ESCs, 12-pole motors. This is the tune she flew on BF3D v0.3.1
# (Betaflight 4.5.1, test passes 34-56), translated to the 2026.6 settings names. A code comparison shows the same D / D-max,
# feedforward and I-term behaviour, but it has NOT flown on the 2026.6 base yet: treat the first pack as a test (hover first).
# It is a starting point for other 31 mm whoops: different motors / props / weight may want other PIDs.
#
# YOU NEED FIRST
#   - BetaFlight 3D Edition v0.3.3-test firmware on your board (BOARDS.md). On stock Betaflight the 3D settings below don't exist:
#     the batch refuses to save, nothing is changed.
#   - 3D already set up and flying: `feature 3D` on, ESCs in bidirectional / 3D mode (AM32 / Bluejay), motor directions and
#     yaw_motors_reversed correct (this file doesn't change them), `dshot_bidir = ON` with `motor_pwm_protocol = DSHOT600` and RPM
#     telemetry (the RPM filter, 3D RPM release and dynamic idle all need it).
#   - Set YOUR motor pole count (`set motor_poles = 12` for the usual 12-pole whoop motors): dynamic idle and the RPM filter read rpm
#     from it. Wrong pole count = wrong rpm.
#   - `pid_process_denom` and `small_angle` are left alone (the Lucid runs denom 1 on its 8 kHz gyro and the default small_angle 25).
#
# HOW TO USE (Betaflight Configurator > CLI)
#   1. Back up first: type `diff all`, copy it somewhere safe.
#   2. Paste this whole file (or "Load from file"). It overwrites PID profile 0 and names it "LilHorny".
#   3. If any ###ERROR### shows up, NOTHING was saved: type `exit` and tell us the line. Otherwise it saves and reboots.
#   4. Props OFF, battery in: check all four motors spin the right way in both directions and idle smoothly. Then hover test.
#
# Dynamic idle is set to 5000 rpm (dyn_idle_min_rpm 50), the value flown on the whoop; keep it below the rpm your slowest motor idles at
# with the stick centered, or set it to 0 to turn it off. Stick settings: 3d_deadband_low 1496 / high 1504 / neutral 1500, throttle
# deadband 3 (tight: raise it if a touch at center reverses the motors), stick deadbands 3. Change them to taste.
# ==============================================================================
