# ==============================================================================
# BetaFlight 3D Edition: 5-inch 3D TUNE (paste-in), "Unicorn 5-inch MAIN" for BF3D v0.3.3-test (Betaflight 2026.6.2)
#
# This is NOT a full `diff all`: it changes the tune only and never touches your board, ports, switches, motor order or rates, so it
# is safe to paste on any 5-inch. (A real `diff all` starts with `defaults` and your board name and would wipe your own setup.)
#
# Flown by ZoeFPV on a 6S 5-inch 3D quad: Hobbywing XRotor F7, 2010-size ~1950 kv motors, APC 5x4 3D props, AM32 2.22 ESCs, ~700 g
# with a GoPro; hover-tested on a T-Motor F7 twin. Dynamic idle (3000 rpm) has only been hover-tested on the 5-inch so far.
#
# YOU NEED FIRST
#   - BetaFlight 3D Edition v0.3.3-test firmware on your board (BOARDS.md). On stock Betaflight the 3D settings below don't exist:
#     the batch refuses to save, nothing is changed.
#   - 3D already set up and flying: `feature 3D` on, ESCs in bidirectional / 3D mode, motor directions and yaw_motors_reversed
#     correct (this file doesn't change them), bidirectional DShot (`dshot_bidir = ON`) with RPM telemetry.
#   - Set YOUR motor pole count (`set motor_poles = 14` for 12N14P 2010 motors): dynamic idle and the RPM filter read rpm from it.
#   - PID loop: this file leaves `pid_process_denom` alone. The tune was flown at 4 kHz (8 kHz gyro, denom 2). On a 3.2 kHz gyro
#     (BMI270) keep denom 1.
#
# HOW TO USE (Betaflight Configurator > CLI)
#   1. Back up first: type `diff all`, copy it somewhere safe.
#   2. Paste this whole file (or "Load from file"). It overwrites PID profile 0 and names it "Unicorn".
#   3. If any ###ERROR### shows up, NOTHING was saved: type `exit` and tell us the line. Otherwise it saves and reboots.
#   4. Props OFF, battery in: check all four motors spin the right way in both directions and idle smoothly. Then fly.
#
# Your own 3D stick settings are included (3d_deadband_low 1496 / high 1504 / neutral 1500, throttle deadband 3 = tight, raise it if a
# touch at center reverses the motors; stick deadbands 2). Change them to taste after pasting.
# ==============================================================================
